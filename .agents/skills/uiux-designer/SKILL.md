# UI/UX Designer Skill

## Principios de Diseño para Rifas Alejandro GM:
1. **Velocidad de Operación para un Solo Administrador:**
   - La interfaz debe permitir buscar boletos al escribir 1-3 dígitos o los últimos 4 dígitos del celular.
   - Modales ágiles con tecla ESC para cerrar y Enter para confirmar.
   - Colores altamente contrastados: verde neón para pagado, cian/ámbar para apartado, carbón para disponible.

2. **Jerarquía Visual y Accesibilidad:**
   - Modo oscuro puro con superficies elevadas `#12161F` y bordes metálicos `#6E7785` al 18% para no fatigar la vista en jornadas extensas.
   - Etiquetas claras para cada moneda: USD ($), COP (COP$), BS (Bs.).

3. **Confianza para el Cliente:**
   - La pantalla de consulta pública debe parecer un boleto de lotería/deportivo premium oficial, con sellos de verificación, fecha de abono y desglose transparente.
