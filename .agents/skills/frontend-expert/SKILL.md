# Frontend Expert Skill

## Directrices de Implementación Técnica:
1. **Next.js & React:**
   - Separación adecuada entre Server Components y Client Components (`"use client"`).
   - Componentes modulares y reutilizables: `TicketGrid`, `TicketCard`, `StatCard`, `NeonButton`, `Modal`.
   - Manejo de estado limpio para filtros, búsquedas y datos en memoria/API.

2. **Tailwind CSS & Estilos Neón:**
   - Implementación estricta de variables CSS temáticas.
   - Efectos glow optimizados con box-shadow y drop-shadow para rendimiento fluido de 60fps.
   - Responsividad total en mobile, tablet y desktop.

3. **Visualización de Datos:**
   - Gráficos de barras interactivos para recaudación por día/semana y por divisa (USD, COP, BS).
   - Barras de progreso de inversión y cálculo del break-even visual.
